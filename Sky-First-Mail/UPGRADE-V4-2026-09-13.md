# Sky First Mail V4 — 2026-09-13

Bản này nâng trực tiếp source hiện có, giữ nguyên Worker/D1/R2/Resend.

## Nâng cấp chính
- Nút đăng xuất rõ ràng trong tài khoản.
- Quản lý phiên: đăng xuất từng thiết bị và toàn bộ thiết bị khác.
- Hiển thị trạng thái Online/Offline, tự báo khi mất/kết nối lại mạng.
- Footer bản quyền Sky First Network + phiên bản.
- Upload nhiều file khi soạn, hiển thị danh sách/tổng dung lượng, giới hạn 8 MB.
- Tự lưu bản nháp vào D1/R2 và mở/xóa bản nháp.
- Đánh dấu toàn bộ thư trong thư mục là đã đọc.
- Thùng rác có Khôi phục và API xóa vĩnh viễn; R2 chỉ xóa khi object không còn thư nào tham chiếu.
- Endpoint dung lượng mailbox và health check.
- Chống nhận trùng inbound theo Message-ID.
- Chống tạo hai bản inbox nội bộ nếu cùng mailbox xuất hiện ở To và Cc.
- Có API xóa Contact, Signature, Rule và bật/tắt Rule để tiếp tục mở rộng UI.
- Tự reload về màn hình đăng nhập khi session hết hạn ở lớp V4.

## Deploy
1. `npm install`
2. `npm run validate`
3. `npm run db:migrate`
4. `npx wrangler secret put RESEND_API_KEY` nếu Worker chưa có secret.
5. `npm run deploy`

`ensureSchema()` cũng tự tạo bảng V4, nên migration 0004 an toàn cho fresh deploy. Không xóa dữ liệu D1/R2 cũ.
