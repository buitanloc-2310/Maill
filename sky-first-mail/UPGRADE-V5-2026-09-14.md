# Sky First Mail V5 — HTML Mail Studio

## Đã triển khai
- Mail Studio mới: Visual / HTML Source / Preview.
- Import `.html` và gửi dưới dạng HTML body thực.
- Rich text toolbar, gửi thử cho chính mình.
- To / Cc / Bcc; gửi bằng mailbox hoặc alias được cấp.
- Template Center: lưu và nạp mẫu HTML.
- Chữ ký trong composer.
- Drag & drop attachment + giới hạn 8 MB.
- Autosave draft có HTML, Bcc, sender identity, reply context.
- Reply / Reply all / Forward mở Mail Studio.
- MIME multipart/alternative + multipart/mixed.
- In-Reply-To / References cho reply.
- Delivery-event nền tảng cho Resend.
- UI/API version V5.

## Deploy
```bash
npm install
npm run db:migrate
npm run validate
npm run deploy
```
