# Sky First Mail V5 Pro — Compose Upgrade

Đợt nâng cấp tập trung vào trải nghiệm soạn/gửi hiện đại và HTML clipboard.

- Dán HTML từ Gmail/trình duyệt bằng Ctrl+V và giữ table, inline style, màu, logo, nút, khoảng cách.
- Loại script/iframe/object/embed/form và event handler nguy hiểm khi dán.
- Toolbar mở rộng: undo/redo, font, cỡ chữ, bold/italic/underline/strike, màu chữ, highlight, căn lề, list, indent/outdent, link, ảnh URL, emoji, divider, quote, clear format.
- Visual / HTML Source / Preview.
- Import HTML bằng chọn file hoặc kéo thả file .html vào composer.
- Fullscreen composer, word/character counter, recipient counter.
- Reply-To và priority High/Normal/Low khi gửi ra ngoài.
- Xóa từng attachment, paste ảnh thành attachment, drag/drop nhiều file.
- Ctrl/Cmd+Enter để gửi, Ctrl/Cmd+S để lưu nháp.
- Cảnh báo khi đóng khi có thay đổi chưa lưu.
- Giữ các tính năng V5: Bcc, alias, template, signature, send test, autosave draft, reply/reply-all/forward, HTML multipart.

Không có migration D1 mới trong đợt V5 Pro này. Nếu database đã chạy migration 0005_v5_mail_studio.sql thì không cần chạy thêm SQL.
